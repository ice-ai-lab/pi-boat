侧栏头部设计提案 · 四档对照

目标是让左上角这块回答三个问题：我该在哪个项目里干活、怎么开一个新的、怎么找回旧的。四档改法只差「要不要动 v4 规范的三段结构」，其余全部按现有 token 渲染，可直接对照 docs/design/piboat-web-v4.html。

鼠标移到会话行上可看 hover 出图标的几何；方案 2 / 3 点头部的放大镜可试「就地替换」的搜索态。

全部 mock 尺寸 1:1，侧栏宽 260px（--sb-w）

现状

98px
  • 品牌行 54px 只放 6 个字符 + 1 个按钮
  • 全侧栏唯一的实体按钮（白底 + 描边）是低频动作
  • 品牌 14px 与项目名 12px 上下紧贴 → 两个标题互抢
  • 四套图标几何：31 / 30×30 r8 / 26×26 r5 / 32×32 r7
  • 头部 98px 之后直接进列表：无分组、无锚点

方案 1 · 同族化

规范成本 088px
  • 三段结构不动，只统一几何：图标按钮全 26×26 / r6 / icon 13
  • 「新会话」去白底描边 → ghost 胶囊，hover 才出底
  • 品牌降为 12px / text-muted，层级让给项目名
  • 工作区行 35 → 34，上间距 9 → 6
  • 仍可逐条对回 v4 规范，无需豁免

方案 2 · 合并身份行

推荐46px
  • 品牌行 + 工作区行合成单行：项目选择器（主）+ [+] + [⌕]
  • + 贴住项目名 = 动作带上作用域，对齐 ADR-0026
  • 分支移进下拉，hover 项目名时以 title 显示
  • 点 ⌕ 就地替换整行，不再插行把列表顶下去
  • 省下 52px ≈ 列表多显示一行

方案 3 · 列表升格

方案 2 + 分组46 + 26
  • 日期分组头：今天 / 昨天 / 本周 / 更早（10.5px 650 ls .10em）
  • meta 状态优先：⟳ 运行中 → ● 未读 → 时间
  • 「313 条消息」降为 title tooltip，meta 只留状态
  • 技术前提：窗口化由「固定 54px 行高」改为前缀和高度映射
